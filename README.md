Project Name: Online Store (PHP MVC Application)
Project Description

This project is a simplified online store web application developed using PHP and MySQL. The application allows users to browse a product catalog, add items to a shopping cart, update quantities, and complete a checkout process. The project was built incrementally over multiple weeks and refactored into an MVC (Model-View-Controller) architecture to improve organization, maintainability, and separation of concerns.

Project Tasks

Task 1: Project planning

Create a project plan and define weekly milestones

Break the application into manageable development phases

Task 2: Database design and setup

Design database schema for products and cart items

Create tables and seed initial product data

Task 3: Backend development

Implement database connectivity using MySQLi

Develop CRUD operations for products and cart functionality

Task 4: MVC architecture refactor

Separate application logic into Models, Views, and Controllers

Implement routing through a front controller

Task 5: Shopping cart functionality

Add items to cart

Update quantities and remove items

Calculate subtotal, tax, shipping, and order total

Task 6: Testing and finalization

Perform manual functional testing of all application features

Document testing results and finalize project submission

Project Skills Learned

PHP backend development

Using MySQLi with prepared statements

Implementing MVC architecture

Session-based shopping cart functionality

Manual application testing

Version control using Git and GitHub

Writing technical documentation

Language and Technologies Used

PHP: Server-side application logic

MySQL / MySQLi: Database management and queries

HTML: Page structure and content

CSS (minimal): Basic layout and readability

Development Process Used

Incremental / Agile-style development:
The project was developed in weekly stages, with functionality added and refined each week. Adjustments were made as requirements evolved, including a mid-project refactor to MVC architecture.

Notes

The database can be created by importing the included schema.sql file, which contains both table structure and seed data.

The application is designed to run locally using XAMPP.

Access the application through index.php in a web browser.

Shopping cart data is session-based and resets upon checkout.
