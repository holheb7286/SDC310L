Project Name: Online Store (PHP MVC Application)
Project Description

This project is a simplified online store web application developed using PHP and MySQL. The application allows users to browse a product catalog, add items to a shopping cart, update quantities, and complete a checkout process.

The project was developed incrementally over multiple weeks and refactored into an MVC (Model-View-Controller) architecture to improve organization, maintainability, and separation of concerns. In the final phase, the application received a UI redesign, including modern styling, layout improvements, and optional product images to create a more polished, user-friendly experience.

Project Tasks
Task 1: Project Planning

Create a project plan and define weekly milestones

Break the application into manageable development phases

Task 2: Database Design and Setup

Design a database schema for products and cart items

Create tables and seed initial product data

Task 3: Backend Development

Implement database connectivity using MySQLi

Develop CRUD operations for products and cart functionality

Task 4: MVC Architecture Refactor

Separate application logic into Models, Views, and Controllers

Implement routing through a front controller

Task 5: Shopping Cart Functionality

Add items to cart

Update quantities and remove items

Calculate subtotal, tax, shipping, and order total

Task 6: UI Redesign and Finalization

Redesign catalog and cart pages with consistent styling

Add a responsive layout, color theme, and improved navigation

Support optional product images

Perform final functional testing and documentation

Development Process Used

Incremental / Agile-style development
The project was developed in weekly stages, with functionality added and refined over time. Adjustments were made as requirements evolved, including a mid-project refactor to MVC architecture and a final UI redesign phase.

Notes

The database can be created by importing the included schema.sql file, which contains both table structure and seed data.

The application is designed to run locally using XAMPP.

Access the application through index.php in a web browser.

Shopping cart data is session-based and resets upon checkout.

Product images are optional and loaded dynamically if present.
